สรุปปัญหา (Root Cause & Fix)
ไฟล์: AD Copy Dat filesv4.py
วันที่: 2026-08-07

==================================================
1. อาการที่พบ
==================================================
เมื่อเครื่องจักรหยุดรันชั่วคราว ทำให้โฟลเดอร์ต้นทาง (\\{IP}\{Version}\Dat หรือ
\\{IP}\{Machine}\{Version}\Dat) ไม่มีไฟล์ .dat หลงเหลืออยู่ แต่โฟลเดอร์ปลายทาง
(\\172.18.106.224\mc_csv6\QC\logad\{Machine}) ยังคงมีไฟล์ .dat เก่าค้างอยู่ทุกครั้ง
ที่รันสคริปต์ ทำให้ข้อมูลปลายทางไม่ตรงกับสถานะจริงของต้นทาง

==================================================
2. Root Cause
==================================================
ในโค้ดเดิม ฟังก์ชัน clean_and_create_folder(path_save) ซึ่งทำหน้าที่ลบโฟลเดอร์
ปลายทางเดิมแล้วสร้างใหม่ ถูกเรียกใช้เฉพาะภายในเงื่อนไข `if check_file:`
(กรณีที่ต้นทางมีไฟล์ .dat อยู่เท่านั้น)

โค้ดเดิม:
    if check_file:
        print(mc, ': total', len(check_file), 'files')
        path_save = os.path.join(r"\\172.18.106.224\mc_csv6\QC\logad", mc)
        clean_and_create_folder(path_save)
        for file in check_file:
            ...
    else:
        print(mc, ': No .dat files found')   # <- ไม่แตะโฟลเดอร์ปลายทางเลย

เมื่อเครื่องจักรหยุดรันและต้นทางไม่มีไฟล์ .dat โค้ดจะเข้า branch `else` ซึ่งแค่ print
ข้อความ แล้วไม่ทำการล้าง/อัปเดตโฟลเดอร์ปลายทางใด ๆ ส่งผลให้ไฟล์ .dat ที่เคย copy
ไว้จากรอบก่อนหน้า (ตอนเครื่องยังรันอยู่) ยังคงค้างอยู่ที่ปลายทางตลอดไป จนกว่าเครื่อง
จะกลับมารันและมีไฟล์ .dat ใหม่เข้ามาแทนที่

พูดสั้น ๆ คือ ปลายทาง sync กับต้นทางแบบทิศทางเดียว (เติมไฟล์ใหม่เข้าไปเมื่อมี)
แต่ไม่เคยเคลียร์ทิ้งเมื่อต้นทางว่างเปล่า

==================================================
3. การแก้ไข (Fix)
==================================================
ย้ายการเรียก clean_and_create_folder(path_save) ออกมาไว้ระดับเดียวกับการเช็ค
os.path.isdir(ip) แทนที่จะอยู่ใน if check_file: เท่านั้น

โค้ดที่แก้ไข:
    if os.path.isdir(ip):
        check_file = glob.glob(rf"{ip}\*.dat")

        path_save = os.path.join(r"\\172.18.106.224\mc_csv6\QC\logad", mc)
        clean_and_create_folder(path_save)

        if check_file:
            print(mc, ': total', len(check_file), 'files')
            for file in check_file:
                ...
        else:
            print(mc, ': No .dat files found')
    else:
        print(mc, "Cannot Connect")

พฤติกรรมหลังแก้ไข:
- เชื่อมต่อต้นทางได้ (isdir(ip) = True) -> ล้างและสร้างโฟลเดอร์ปลายทางใหม่เสมอ
  ไม่ว่าต้นทางจะมีไฟล์ .dat หรือไม่ก็ตาม
    - มีไฟล์ .dat -> ล้างแล้ว copy ไฟล์ใหม่เข้าไป (เหมือนเดิม)
    - ไม่มีไฟล์ .dat (เครื่องหยุดรัน) -> ล้างปลายทางให้ว่างตามจริง ไม่มีไฟล์เก่าค้าง
- เชื่อมต่อต้นทางไม่ได้เลย (Cannot Connect) -> ไม่แตะโฟลเดอร์ปลายทาง คงข้อมูลเดิมไว้
  (กันกรณี network/share หลุดชั่วคราว ไม่ให้ลบข้อมูลปลายทางโดยไม่จำเป็น)

4. หมายเหตุอื่น ๆ ที่พบระหว่างรีวิว (ยังไม่ได้แก้ในรอบนี้)
==================================================
- Comment บรรทัด "ถ้าชื่อสั้นกว่า 10 ตัวอักษร -> ข้าม" ไม่ตรงกับเงื่อนไขจริงในโค้ด
  ซึ่งเช็คว่า name_length < 15
- ตัวแปร factory กำหนดจากชื่อเครื่อง PC เพียงชื่อเดียว (2592P-ED363 = 'A' ที่เหลือ
  ทั้งหมดถือเป็น 'E') หากมีมากกว่า 2 โรงงานจริง ควรพิจารณาปรับ logic นี้เพิ่มเติม
- ไม่มีการดักจับ exception (try/except) รอบการเชื่อมต่อ DB หรือ shutil.copy
  หาก DB ล่มหรือ copy ไฟล์ล้มเหลวกลางทาง สคริปต์จะหยุดทำงานทั้งหมดทันที
